# Percentage Calculator
Calculate the percentage of any amount given,
This only runs on Laptops and desktops up to 23"

## Description
This project was made with HTML, CSS, Javascript and made public using Github Pages.
This is a percentage calculator.
I built this project to help me practice working with numbers in javascript, it did help lots. im eventually going to make a calculator and this project will have taught me a few things that i need to make it.


It calculates the percentage of a amount e.g 25% of 100 = 25
To use it:
- Enter the amount/number (e.g 100) you want to find the percentage of
- Enter the percentage (e.g 25) (Without percentage sign)
- press submit and the awnser will appear
And Press clear if you would like to find a percentage of another amount.

## Run Locally
- Download the project files - index.html, style.css and script.js
- Place all the downloaded files into one folder on your Laptop/Desktop.
- Open index.html in your web browser to use the Percentage calculator.

## Modify Locally
- Download the project files - index.html, style.css and script.js
- Place all the downloaded files into one folder on your Laptop/Desktop.
- Open index.html to change the webpage structure / order.
- Open style.css to style the html elements the way you want.
- Open script.js to change the features of the elements.
- Reload the page to see your changes made (changes only for you) or you could host it using Github pages to make it public.
